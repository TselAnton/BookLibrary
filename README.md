# BookLibrary
### Описание
Небольшая программа, исключительно для домашнего использования, 
которая позволяет вести собственную домашнюю книжную библиотеку 
с отслеживанием и аггрегацией имеющихся книг. 

### Сборка
- JDK 17, JavaFX 21.0.12 LTS, Maven
- Maven: mvn clean package

Запуск: `java -jar target/BookLibraryApp.jar` или `mvn javafx:run`.

Результаты и разбор задержки на 851 книге: [замеры запуска](design/startup-analysis.md).

Обложки загружаются в фоне: общая контрастная обложка заменяется изображением книги
по мере готовности. При отсутствии или ошибке чтения файла остаётся общая обложка.

Интерфейс использует светлую шалфейную тему из `design`: компактную шапку,
адаптивную таблицу, формы добавления и редактирования и карточку книги.
Аудиокнопки скрыты согласно спецификации; сохранённые связи остаются в данных.

`Ctrl+N` добавляет книгу, `Ctrl+F` открывает фильтры, `Enter` на выбранной
строке открывает карточку. Отбор книг выполняется только через панель фильтров;
поисковой строки и командного синтаксиса больше нет. Масштаб таблицы можно
менять с помощью Ctrl и колеса мыши.

Кнопка «Фильтры» открывает правую панель. Логические признаки и справочники
выбираются чекбоксами со счётчиками, для чисел доступны диапазоны и сравнения,
для названия — текстовые условия. «Применить» сохраняет настройки, «Отмена»
и Escape отбрасывают черновик. Снизу панели кнопки доступны при любой прокрутке.
Списки значений показывают первые пять вариантов с возможностью раскрытия;
при поиске отображаются все совпадения. Условия отображаются компактными тегами;
стрелка раскрывает остальные строки, кружок рядом показывает число скрытых тегов.
Раскрытие и применённые условия сохраняются при просмотре и изменении книг.
Значения и счётчики фильтров кешируются в фоне при запуске и обновлении каталога;
повторное открытие панели использует готовые данные и существующие элементы.
Параметр запуска `-Dbooklibrary.reducedMotion=true` отключает выезжание панели.

Расширение фильтров описано в `design/windows/filters.md`: метаданные задаются
через `@FilterProperty`, поддерживаемые Java-типы — через `@FilterTypes` на процессоре.
Ядро находится в пакете `filter`: аннотации — `annotation`, условия — `condition`,
модели — `model`, процессоры — `processor`, источники значений — `provider`,
фоновый кеш — `cache`. Реализации процессоров и источников выделены в `impl`.
Панель и теги находятся в `ui.filter`, редакторы — в `ui.filter.editor` и `impl`.
Текстовые условия и поиск внутри списков не зависят от регистра и различия
«е»/«ё»: «СЕМЕН» находит «Семён». Спецсимволы в текстовом условии считаются обычным текстом.

Проверки: `mvn test`. `SageViewsTest` проверяет реальные окна JavaFX и операции
с отдельным временным каталогом, включая компактный режим и защиту черновика.
Для проверки DPI: `mvn -Dtest=SageViewsTest -Dglass.win.uiScale=1.5 test`.
`FilterCatalogTest` проверяет условия, пустые значения, счётчики и регистрацию
новых типов. `NumericFilterProcessorTest` проверяет сравнения и границы чисел,
`FilterOptionCacheTest` — фоновый кеш и обновление после изменения книг.
`-Dbooklibrary.captureFilters=true` сохраняет снимки проверяемого
интерфейса в `target/filters-*.ppm`.

Фильтры обязательных полей не предлагают проверок заполненности. Для цены
«Бесценно» означает отсутствие сохранённой стоимости, а «Подарок» — нулевую цену;
проверка «Стоимость указана» включает ноль. Поиск подстроки цифр удалён.
Русский Javadoc описывает контракты классов и публичных методов фильтров.
[Анализ потоков, памяти и зависимостей кеша](design/filter-cache-analysis.md).
