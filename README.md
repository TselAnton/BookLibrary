# BookLibrary
### Описание
Небольшая программа, исключительно для домашнего использования, 
которая позволяет вести собственную домашнюю книжную библиотеку 
с отслеживанием и аггрегацией имеющихся книг. 

### Сборка
- JDK 17–21 (байткод Java 17), JavaFX, Maven
- Maven: mvn clean package

Запуск: `java -jar target/BookLibraryApp.jar` или `mvn javafx:run`.

Интерфейс использует светлую шалфейную тему из `design`: компактную шапку,
адаптивную таблицу, формы добавления и редактирования и карточку книги.
Аудиокнопки скрыты согласно спецификации; сохранённые связи остаются в данных.

`Ctrl+N` добавляет книгу, `Ctrl+F` переводит фокус в поиск, `Enter` на выбранной
строке открывает карточку. Поиск применяется по Enter. Сброс фильтров сохраняет
текст запроса. Масштаб таблицы можно менять с помощью Ctrl и колеса мыши.

Проверки: `mvn test`. `SageViewsTest` проверяет реальные окна JavaFX и операции
с отдельным временным каталогом, включая компактный режим и защиту черновика.
Для проверки DPI: `mvn -Dtest=SageViewsTest -Dglass.win.uiScale=1.5 test`.
