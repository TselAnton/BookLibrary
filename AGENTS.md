# Правила проекта

Перед добавлением или изменением кода обязательно прочитать [style_design.md](style_design.md) и следовать ему во всём новом и изменяемом коде, включая тесты, FXML, CSS и XML.

Использовать основные правила стандарта и учитывать описанные в нём локальные варианты существующих файлов. Не переформатировать несвязанный код. При появлении новой конструкции дополнять стандарт примером из проекта.
